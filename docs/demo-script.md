# 答辩演示脚本

## 1. 启动与身份

运行 `docker compose up --build`，打开 `http://localhost:5173/login`。使用 `admin / AgentDesk@2026` 登录管理员后台，或使用 `zhangsan / AgentDesk@2026` 登录员工工作台；首次登录会要求修改密码。员工也可以注册，注册后由管理员审核部门。

## 2. 员工提单与权限

创建“VPN 无法连接”工单，展示状态为 NEW。尝试访问另一位员工的工单，应返回 403，说明数据隔离生效。

## 3. Agent 分类与检索

点击分类摘要，展示 LLM（默认 GLM glm-5.3-flash，可在顶栏切换 DeepSeek）或规则兜底来源、NETWORK、P2、处理队列、置信度和失败原因字段。点击带引用回复，展示引用文章 ID、版本 ID 和原文片段；在知识问答中搜索不存在的问题，展示无证据拒答。

## 4. 处理工作台与人工确认

管理员在队列页面给处理人授权；处理人登录后进入“处理工作台”，只看到自己队列的工单，运行推荐并生成 TRANSFER 待审批动作。处理人可以将工单标记为已分析、处理中或已解决，并在工单详情中追加评论、上传附件。管理员在“审批与审计”批准或驳回，展示动作状态和审计记录。

## 5. 企业资料

管理员在“资料与知识”上传 PDF、DOCX、TXT 或 Markdown。Agent 负责解析，LLM 生成摘要和要点，系统创建待审核知识文章；管理员在知识文章审核区确认后发布，发布后按公开或部门授权参与问答。

## 6. 结论

说明 LLM（GLM / DeepSeek，OpenAI 兼容接口可扩展）负责分析和问答，PostgreSQL 全文检索负责证据召回；重点成果是流程、部门权限、队列分流、人工确认、审计和一键部署。
